# TIL (Today I Learned) 
이 레포지토리는 데이터 분석가로서 일상적으로 학습하고 경험한 내용을 정리하는 공간입니다. <div>
주로 데이터 분석을 위한 전처리 과정에서 얻은 인사이트와 기술적 팁을 다룹니다. <div>
  
## 목차 
  
<div>
  
### 1. 데이터 처리 
이 섹션에서는 효율적인 데이터 마트 구축을 위한 다양한 기법과 방법론을 다룹니다.
<div>
  
* 원본 데이터에서 필요한 정보 추출하기<div>
* 데이터 정제 및 변환 프로세스<div>
* 데이터 마트 설계<div>
* 성능 최적화를 위한 인덱싱 전략<div>
* 데이터 품질 관리 방법<div>
<div>

### 2. ERROR 처리
데이터 분석 과정에서 발생할 수 있는 다양한 에러와 그 해결 방법을 정리합니다.
<div>

* 일반적인 데이터 로딩 에러와 해결책<div>
* 데이터 타입 변환 시 주의사항<div>
* 메모리 관리와 대용량 데이터 처리 팁<div>
* 예외 처리를 통한 안정적인 코드 작성법<div>
* 디버깅 기법과 툴 활용 방법<div>
<div>

### 3. 데이터 집계 방법 정리
다양한 상황에서 활용할 수 있는 데이터 집계 방법을 소개합니다.
<div>
  
* 기본 통계 함수를 이용한 집계 <div>
* 그룹별 집계와 피벗 테이블 활용법<div>
* 시계열 데이터 리샘플링과 이동평균 계산<div>
* 고급 집계 기법 (사용자 정의 함수, 윈도우 함수 등)<div>
* 데이터 시각화를 위한 효과적인 집계 방법<div>
